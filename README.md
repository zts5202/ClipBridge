# ClipBridge

在同一局域网里，把 Android 手机和 Windows 电脑的剪贴板、图片、文件接在一起。不需要账号，不经过公网。

当前版本：`1.2.2+6`  
应用 ID：`app.clipbridge.clipbridge`  
开发与 CI 使用的 Flutter：**3.47.6 stable**（Dart **3.13.5**）

## 功能

- 同一 Wi-Fi，或手机热点给电脑时，用 UDP 广播发现对方（端口 **47821**）。列表里能看到设备名、手机/电脑、在线状态。发现不到时可以手动填 IP。
- 新设备必须两端都确认。确认框显示 6 位安全码和指纹，45 秒未确认则拒绝。
- 已配对设备可自动重连（设置里可关）。手动断开后，在重新打开自动重连或再次手动连接之前，不会立刻自动拨回去。
- 会话加密：Ed25519 身份、X25519 握手、AES-256-GCM。剪贴板和文件不以明文发送。同一时间只保持一条活动会话。
- 双向传输文字、图片（PNG / JPEG / WebP）和文件。分块传输、SHA-256 校验、进度、失败可重试。默认单次上限 **200MB**，可在 1MB–2048MB 之间调整。
- 手机：应用内发送文字、图片、文件；也可从系统分享面板分享到 ClipBridge（多文件分享只发送第一个）。收到的文字写入剪贴板；图片和文件保存到应用接收目录，并尽量写入相册或「下载」。
- 电脑接收方式：
  - **仅剪贴板**：写入系统剪贴板，自己 Ctrl+V。
  - **剪贴板并自动粘贴**：写入剪贴板后用 SendInput 模拟 Ctrl+V。失败时仍保留剪贴板，并用托盘通知说明原因（焦点在本窗口、目标进程权限更高、系统拒绝按键等）。
- 电脑可打开「自动同步复制的内容」。复制文字或图片后发给已连接的手机。也可手动发送当前剪贴板或选择文件。
- 手机以前台服务保持在线（需要通知权限）。电脑在系统托盘常驻：显示主窗口、隐藏主窗口、暂停同步、退出。点关闭按钮会藏到托盘，退出请用托盘菜单。
- 「发送前确认」只作用于手动发送。自动同步不受这个开关影响。暂停同步后保持连接，但不再收发内容。

界面为简体中文，Material 3。

## 权限

### Android（API 26+）

| 权限 | 用途 |
| --- | --- |
| 网络、Wi-Fi 状态、组播 | 发现设备和建立会话 |
| 通知、前台服务（connectedDevice） | 后台保持局域网连接，显示常驻通知 |
| 存储（仅 Android 9 及更早） | 把收到的文件放到公共目录 |

图片和文件通过系统选择器读取，不申请整个存储空间。Android 13+ 启动时会请求通知权限；拒绝后前台服务可能无法保持，应用退到后台时连接会中断。

### Windows 10/11 x64

首次启动时，防火墙请选择允许 **专用网络**。托盘图标使用应用图标。自动粘贴不需要额外辅助功能权限，但无法粘贴到比本程序权限更高的窗口（例如以管理员运行的程序）。

## 配对

1. 手机和电脑安装并打开 ClipBridge，处于同一局域网。
2. 在「设备」页看到对方后点连接。两端都会弹出确认框，请核对 **相同的 6 位安全码**，两边都点接受。
3. 首页变为已连接。之后只要「自动重连已配对设备」开着，再次出现在同一网络时会直接恢复会话，不再弹确认。
4. 可断开、忘记设备，或在设置里改本机显示名（最多 32 字）。忘记设备后，下次连接会重新确认。若对端更换了身份密钥，需要先忘记该设备再配对。

发现端口 UDP `47821`，会话端口 TCP `47822`（若被占用会向后尝试若干端口，并写进发现广播）。只使用 IPv4。

## 接收文件放在哪

- Windows：用户「下载」目录下的 `ClipBridge`。设置页可「打开接收目录」。
- Android：应用接收目录，同时尝试发布到相册（图片）或公共「下载」。

本地传输记录可以在「记录」页清空。记录不会上传。清空记录不会删除已经保存的文件。


Release 的 APK 和 AAB 使用仓库里的 `android/clipbridge-release.jks`（别名 `clipbridge`，口令写在 `android/clipbridge-signing.properties`）。这是一把专供旁加载的固定证书，证书 SHA-256 以 `6628A3CA` 开头。v1.1.0 和 v1.1.1 的 CI 每次都生成新的 debug keystore，所以装过那些版本的手机必须先卸载再安装。v1.2.0 与本版使用同一把证书，可以直接覆盖升级。

这把密钥和口令是公开的，只保证「每次安装包是同一签名」，不能当作私密的上架密钥。谁拿到仓库都能用它签名。若要上架，请换成自己的密钥，或在 GitHub Actions 里设置 `CLIPBRIDGE_KEYSTORE_BASE64`、`CLIPBRIDGE_STORE_PASSWORD`、`CLIPBRIDGE_KEY_ALIAS`、`CLIPBRIDGE_KEY_PASSWORD`，构建时会优先用这组 secret。本环境没有仓库 secret 的写权限，所以密钥提交在仓库里。

## Windows 贴边悬浮条

电脑端不再打开大主窗口。启动后是屏幕右边缘的一条半透明小条，加上托盘图标。光标进入小条约 8px 范围内，或停在小条上约 150ms，面板滑出；离开约 600ms 后收回。收回只是把面板收起来，已连接的会话保持连接。点击小条或托盘「显示并钉住面板」可以钉住，钉住后离开也不收回。面板里有连接状态、接收方式、发送剪贴板或文件、最近 5 条记录。齿轮打开同一面板里的设置：已配对设备、忘记、重命名、自动重连、文件上限、左右贴边、开机自启、提示音，以及手动 IP、附近设备和接收目录。托盘菜单是「显示并钉住面板」「暂停/继续同步」「开启/关闭自动同步」「开启/关闭开机自启」「开启/关闭提示音」「退出」，文字用 UTF-8 转成 UTF-16，避免乱码。连接、断开和发送默认不播放提示音。

窗口是无边框置顶工具窗口（`WS_EX_NOACTIVATE`、`WS_EX_TOOLWINDOW`），不出现在任务栏，滑出时不抢走当前窗口的键盘焦点，这样自动粘贴仍打到原来的前台程序。面板和小条是磨砂玻璃：Windows 11 用 DWM Acrylic（`DWMWA_SYSTEMBACKDROP_TYPE`），Windows 10 用 `SetWindowCompositionAttribute` 的 Acrylic，失败时退化为模糊。Flutter 只画一层约 0.82 透明度的底色，文字画在上面，所以壁纸能透出来，字仍然是实心的。没有使用 `WS_EX_LAYERED`，避免整窗一起变淡或者交换链变黑。全屏窗口盖住显示器时小条会藏起来；桌面本身（Progman / WorkerW）不算全屏。位置按工作区边缘和比例记住，分辨率或显示器变化后会夹回可见区域。Android 仍是原来的四页界面。

## 热点和 Wi-Fi

- **同一 Wi-Fi**：两端都连到没有「AP 隔离 / 访客网络隔离」的网络。公用网络配置文件有时会拦住入站连接，请在 Windows 防火墙里允许 ClipBridge。
- **手机热点**：打开手机热点，让电脑连接这个热点。不必经过同一台路由器。若广播被系统丢掉，在「设备」页输入对方 IP（手机热点网关常见为 `192.168.43.1` 或 `192.168.137.1`，以设备页显示的本机地址为准）。
- 电脑休眠、手机省电杀掉应用、切换网络后，打开自动重连并保持应用在前台服务中，会尝试恢复。仍失败时手动点一次连接。

## USB 网络共享

手机用 USB 线给电脑共享网络时（Android 的 RNDIS/NCM，电脑上常显示为「远程 NDIS」），ClipBridge 不检查 Wi-Fi。发现和会话仍监听全部 IPv4 地址。Windows 常把这块网卡标成公用网络，拦进入站 UDP `47821` 和 TCP `47822`，所以手机发来的广播进不了电脑。

电脑会自己发起出站流量，让回复沿着已建立的连接回来：

- 若本机地址落在 `192.168.42.0/24`–`192.168.49.0/24`（Android 的 USB 共享地址池），每隔两秒向该网段的 `.129` 和 `.1` 发单播发现（排除本机自己的地址）。手机收到后单播回复。
- 若还没发现对方，再按大约每 3 秒一次，轮流尝试向这两个地址的 TCP `47822`–`47841` 主动连接。不会扫描整段 254 个地址。
- 已经配对且打开了自动重连：电脑直接连上。
- 还没配对：电脑仍会连出，但两端都要确认验证码，规则和 Wi-Fi 配对相同。拒绝或超时后，大约一分钟内不会反复弹窗。
- 手动断开后，自动连接暂停，直到你再次手动连接。

手机不会反过来扫描电脑所在的地址段，因为那些包对 Windows 来说仍是入站，公用网络会丢掉。

若仍然连不上：在 Windows 防火墙里允许 ClipBridge 通过公用网络，或把这块 USB 网卡改成专用；也可以在电脑的设备页输入手机上显示的地址（很多机型是 `192.168.42.129`）。本环境没有接 USB 线实测。

## 连接保持与托盘文字

同一对设备只保留一个活动连接。Wi-Fi 上由设备 ID 字典序较小的一端发起自动重连，另一端只接受；USB 网络共享仍由电脑连出。已经连上的对端，发现刷新和探测都不会再拨号。重复连入时保留仍在心跳内的连接，丢掉新的那条。

心跳每 5 秒一次，连续 3 次没有回应（约 15 秒）才断开。断开后按 1 秒、2 秒、4 秒退避重连，最长 30 秒。10 秒内恢复不弹通知；超过 10 秒提示一次「已断开」，恢复后再提示一次「已重新连接」。首次连上提示一次「已连接」。窗口和托盘上的状态马上更新。调试日志带发起方、连接 ID 和断开原因（心跳超时、对端关闭、被重复连接替换、网络地址变化）。

托盘菜单不走第三方插件。菜单和初始提示用宽字符 API，把 UTF-8 转成 UTF-16；Windows 工程另加了 `/utf-8`。通知、后来的托盘提示、资源管理器路径同样从 UTF-8 转成 UTF-16。窗口标题是英文 `ClipBridge`。选择文件用的是 file_picker，文字由 Flutter 以 UTF-8 传入。

## 手动测试清单（对应验收）

请用一台 Android 8.0+ 手机和一台 Windows 10/11 x64 电脑，安装本次构建的 APK 与 Windows 压缩包。

- [ ] **同 Wi-Fi 发现并配对。** 两端打开应用，设备页出现对方。点连接后两边都弹出确认，安全码一致。只点一边接受、或等到超时，会话不应建立。
- [ ] **旧设备自动重连。** 断开或重启一端后，在自动重连开启时恢复已连接，且不再要求确认。关闭该开关后，不应自动连上。忘记设备后，再次连接必须重新双方确认。
- [ ] **手机文字到电脑剪贴板。** 默认「仅剪贴板」时，手机发送文字，电脑记事本 Ctrl+V 得到原文。
- [ ] **自动粘贴。** 电脑改为「剪贴板并自动粘贴」，焦点放在记事本，手机再发文字，记事本直接出现内容。焦点留在 ClipBridge 窗口、或目标是管理员窗口时，应看到失败通知，剪贴板里仍有文字。
- [ ] **电脑文字到手机。** 打开电脑「自动同步复制的内容」，在别的程序复制一段文字，手机剪贴板可以粘贴出同一段。关闭自动同步后，用「发送剪贴板」仍可手动发出。
- [ ] **双向图片。** 分别发送 PNG、JPEG、WebP。对端有进度；电脑能在剪贴板或接收目录看到图片；手机能保存，并可在相册或接收目录打开。
- [ ] **双向文件。** 发送一个小于上限的文件，两端都有进度，接收方能打开保存结果。再发一个超过上限的文件，发送被拒绝且原因可读。传输中断后，记录里失败项可以重试。
- [ ] **手机热点。** 手机关热点、电脑连接该热点，重复发现（或手动 IP）、配对、发一条文字。主流程可用。
- [ ] **USB 网络共享。** 手机打开 USB 网络共享，电脑不要手动填 IP。电脑应发现手机并连出。已配对且自动重连开着时直接连上；新设备仍弹出双方确认。若没有出现，允许 ClipBridge 通过公用网络，或手动输入手机地址。
- [ ] **连接保持 30 分钟。** 两端配对后保持连接，Windows 不应循环弹出「已连接 / 已断开」。两端都打开自动重连时，调试日志里同一时刻只有一个活动连接（`open` / `ready` / `close`，带 connection id 和 initiator）。
- [ ] **断网再恢复。** 关掉手机 Wi-Fi 再打开。超过约 10 秒才出现一次「已断开」，连上后再出现一次「已重新连接」。若 10 秒内就恢复，这两条通知都不出现。窗口和托盘状态会马上变化。
- [ ] **只有小条和托盘。** 启动后没有大主窗口，任务栏没有 ClipBridge 按钮。小条默认在右边缘。
- [ ] **滑出、收回、钉住。** 平时能在屏幕边缘看到半透明小条。鼠标靠近小条后面板滑出，移开约 600ms 后收回，已连接的会话不断开。点击小条或托盘钉住后，鼠标离开也不收回。
- [ ] **没有提示音。** 连接、断开、发送文字时不响。托盘「开启提示音」之后，这些通知才出声。关掉后再次静音。
- [ ] **磨砂玻璃。** 浅色和深色下，面板和小条都能透出一点壁纸，文字仍然看得清。
- [ ] **面板四块。** 能看到连接状态、在「仅剪贴板」和「自动粘贴」之间切换、发送当前剪贴板和文件、最近记录最多 5 条。点文字记录会复制，点图片或文件会打开所在位置，失败项可以重试。
- [ ] **自动粘贴不丢焦点。** 面板滑出或收起时，记事本仍保持焦点。手机发来文字后，记事本出现内容。
- [ ] **设置。** 齿轮页可以忘记设备、改文件上限、切换左/右贴边、开关开机自启。托盘里的自动同步和暂停同步也会立刻生效。
- [ ] **托盘中文。** 右键为「显示并钉住面板」「暂停同步」或「继续同步」「开启自动同步」或「关闭自动同步」「开启开机自启」或「关闭开机自启」「开启提示音」或「关闭提示音」「退出」，不是乱码。
- [ ] **外观。** 浅色和深色跟随系统。换到另一台显示器，或把缩放改成 125%、150%，小条仍贴在可见边缘，不跑到屏幕外。全屏播放或游戏时小条隐藏，退出全屏后回来。
- [ ] **托盘与手机前台服务。** 暂停时对端发送应失败且有提示。托盘退出后进程结束。手机通知栏有前台服务；退到后台后仍能收到一条文字（需已授予通知）。
- [ ] **分享。** 从相册或文件管理器分享一张图或一个文件到 ClipBridge，已连接时发出；未连接时提示，连接后可发送。
- [ ] **隐私。** 断网后没有外连重试到公网地址的必要行为；清空记录后列表为空，已保存文件还在接收目录。

## 常见问题

**列表是空的。** 确认不是访客网络或 AP 隔离；Windows 网络是否允许专用网络；两端都在前台或手机前台服务仍在。用设备页上的本机 IP 手动连接。

**一边已点接受，另一边没弹窗。** 确认请求只对「手动连接的新设备」出现。自动重连不会对陌生设备弹窗。请在想连接的那一侧点击设备。

**自动粘贴没发生。** 先看托盘通知。最常见的是焦点还在 ClipBridge，或目标程序权限更高。剪贴板里应已有内容，可手动 Ctrl+V。

**手机收不到。** 检查通知权限、电池优化是否杀掉了 ClipBridge，以及是否点了暂停同步。
