# ClipBridge

在同一局域网里，把 Android 手机和 Windows 电脑的剪贴板、图片、文件接在一起。不需要账号，不经过公网。

当前版本：`1.0.0+1`  
应用 ID：`app.clipbridge.clipbridge`  
开发与 CI 使用的 Flutter：**3.47.6 stable**（Dart **3.13.5**）

## 功能

- 同一 Wi-Fi，或手机热点给电脑时，用 UDP 广播发现对方（端口 **47821**）。列表里能看到设备名、手机/电脑、在线状态。发现不到时可以手动填 IP。
- 新设备必须两端都确认。确认框显示 6 位安全码和指纹，45 秒未确认则拒绝。
- 已配对设备可自动重连（设置里可关）。手动断开后，在重新打开自动重连或再次手动连接之前，不会立刻自动拨回去。
- 会话加密：Ed25519 身份、X25519 握手、AES-256-GCM。剪贴板和文件不以明文发送。同一时间只保持一条活动会话。
- 双向传输文字、图片（PNG / JPEG / WebP）和文件。分块传输、SHA-256 校验、进度、失败可重试。默认单次上限 **200MB**，可在 1MB–2048MB 之间调整。
- 手机：应用内发送文字、图片、文件；也可从系统分享面板分享到 ClipBridge（多文件分享只发送第一个）。收到的文字写入剪贴板；图片和文件保存到应用接收目录，并尽量写入相册或「下载」。
- 电脑接收方式：
  - **仅剪贴板**：写入系统剪贴板，自己 Ctrl+V。
  - **剪贴板并自动粘贴**：写入剪贴板后用 SendInput 模拟 Ctrl+V。失败时仍保留剪贴板，并用托盘通知说明原因（焦点在本窗口、目标进程权限更高、系统拒绝按键等）。
- 电脑可打开「自动同步复制的内容」。复制文字或图片后发给已连接的手机。也可手动发送当前剪贴板或选择文件。
- 手机以前台服务保持在线（需要通知权限）。电脑在系统托盘常驻：显示主窗口、隐藏主窗口、暂停同步、退出。点关闭按钮会藏到托盘，退出请用托盘菜单。
- 「发送前确认」只作用于手动发送。自动同步不受这个开关影响。暂停同步后保持连接，但不再收发内容。

界面为简体中文，Material 3。

## 权限

### Android（API 26+）

| 权限 | 用途 |
| --- | --- |
| 网络、Wi-Fi 状态、组播 | 发现设备和建立会话 |
| 通知、前台服务（connectedDevice） | 后台保持局域网连接，显示常驻通知 |
| 存储（仅 Android 9 及更早） | 把收到的文件放到公共目录 |

图片和文件通过系统选择器读取，不申请整个存储空间。Android 13+ 启动时会请求通知权限；拒绝后前台服务可能无法保持，应用退到后台时连接会中断。

### Windows 10/11 x64

首次启动时，防火墙请选择允许 **专用网络**。托盘图标使用应用图标。自动粘贴不需要额外辅助功能权限，但无法粘贴到比本程序权限更高的窗口（例如以管理员运行的程序）。

## 配对

1. 手机和电脑安装并打开 ClipBridge，处于同一局域网。
2. 在「设备」页看到对方后点连接。两端都会弹出确认框，请核对 **相同的 6 位安全码**，两边都点接受。
3. 首页变为已连接。之后只要「自动重连已配对设备」开着，再次出现在同一网络时会直接恢复会话，不再弹确认。
4. 可断开、忘记设备，或在设置里改本机显示名（最多 32 字）。忘记设备后，下次连接会重新确认。若对端更换了身份密钥，需要先忘记该设备再配对。

发现端口 UDP `47821`，会话端口 TCP `47822`（若被占用会向后尝试若干端口，并写进发现广播）。只使用 IPv4。

## 接收文件放在哪

- Windows：用户「下载」目录下的 `ClipBridge`。设置页可「打开接收目录」。
- Android：应用接收目录，同时尝试发布到相册（图片）或公共「下载」。

本地传输记录可以在「记录」页清空。记录不会上传。清空记录不会删除已经保存的文件。

## 热点和 Wi-Fi

- **同一 Wi-Fi**：两端都连到没有「AP 隔离 / 访客网络隔离」的网络。公用网络配置文件有时会拦住入站连接，请在 Windows 防火墙里允许 ClipBridge。
- **手机热点**：打开手机热点，让电脑连接这个热点。不必经过同一台路由器。若广播被系统丢掉，在「设备」页输入对方 IP（手机热点网关常见为 `192.168.43.1` 或 `192.168.137.1`，以设备页显示的本机地址为准）。
- 电脑休眠、手机省电杀掉应用、切换网络后，打开自动重连并保持应用在前台服务中，会尝试恢复。仍失败时手动点一次连接。

## USB 网络共享

手机用 USB 线给电脑共享网络时（Android 的 RNDIS/NCM，电脑上常显示为「远程 NDIS」），ClipBridge 不检查 Wi-Fi，也不会因为没连 Wi-Fi 而拒绝。发现和会话都监听全部 IPv4 地址（`0.0.0.0`）。每隔两秒，除了 `255.255.255.255`，还会向每个非回环 IPv4 所在的 `/24` 广播，例如 `192.168.42.255`。设备页的本机地址会在接口出现后几秒内更新，方便手动填写。

自动发现在这条链路上常常失败。Windows 经常把这块网卡标成公用网络，默认拦住入站 UDP `47821` 和 TCP `47822`。手机发来的广播进不了电脑；电脑去连手机则是出站，一般可以。请在电脑的设备页输入手机上显示的地址（很多机型是 `192.168.42.129`，以手机实际显示为准），由电脑发起连接。若之前只允许了专用网络，请同时允许公用网络，或把这块 USB 网卡改成专用。

本环境没有接 USB 共享做实测，上述结论来自绑定、接口枚举和 Windows 公用网络防火墙的行为。

## 手动测试清单（对应验收）

请用一台 Android 8.0+ 手机和一台 Windows 10/11 x64 电脑，安装本次构建的 APK 与 Windows 压缩包。

- [ ] **同 Wi-Fi 发现并配对。** 两端打开应用，设备页出现对方。点连接后两边都弹出确认，安全码一致。只点一边接受、或等到超时，会话不应建立。
- [ ] **旧设备自动重连。** 断开或重启一端后，在自动重连开启时恢复已连接，且不再要求确认。关闭该开关后，不应自动连上。忘记设备后，再次连接必须重新双方确认。
- [ ] **手机文字到电脑剪贴板。** 默认「仅剪贴板」时，手机发送文字，电脑记事本 Ctrl+V 得到原文。
- [ ] **自动粘贴。** 电脑改为「剪贴板并自动粘贴」，焦点放在记事本，手机再发文字，记事本直接出现内容。焦点留在 ClipBridge 窗口、或目标是管理员窗口时，应看到失败通知，剪贴板里仍有文字。
- [ ] **电脑文字到手机。** 打开电脑「自动同步复制的内容」，在别的程序复制一段文字，手机剪贴板可以粘贴出同一段。关闭自动同步后，用「发送剪贴板」仍可手动发出。
- [ ] **双向图片。** 分别发送 PNG、JPEG、WebP。对端有进度；电脑能在剪贴板或接收目录看到图片；手机能保存，并可在相册或接收目录打开。
- [ ] **双向文件。** 发送一个小于上限的文件，两端都有进度，接收方能打开保存结果。再发一个超过上限的文件，发送被拒绝且原因可读。传输中断后，记录里失败项可以重试。
- [ ] **手机热点。** 手机关热点、电脑连接该热点，重复发现（或手动 IP）、配对、发一条文字。主流程可用。
- [ ] **托盘、通知、接收方式。** 电脑托盘可显示/隐藏窗口、暂停同步、退出。暂停时对端发送应失败且有提示。关闭窗口后进程仍在，托盘退出后进程结束。手机通知栏有前台服务；退到后台后仍能收到一条文字（需已授予通知）。切换接收方式后，下一次接收立即按新方式工作。
- [ ] **分享。** 从相册或文件管理器分享一张图或一个文件到 ClipBridge，已连接时发出；未连接时提示，连接后可发送。
- [ ] **隐私。** 断网后没有外连重试到公网地址的必要行为；清空记录后列表为空，已保存文件还在接收目录。

## 常见问题

**列表是空的。** 确认不是访客网络或 AP 隔离；Windows 网络是否允许专用网络；两端都在前台或手机前台服务仍在。用设备页上的本机 IP 手动连接。

**一边已点接受，另一边没弹窗。** 确认请求只对「手动连接的新设备」出现。自动重连不会对陌生设备弹窗。请在想连接的那一侧点击设备。

**自动粘贴没发生。** 先看托盘通知。最常见的是焦点还在 ClipBridge，或目标程序权限更高。剪贴板里应已有内容，可手动 Ctrl+V。

**手机收不到。** 检查通知权限、电池优化是否杀掉了 ClipBridge，以及是否点了暂停同步。
